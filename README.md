# OCR-using-Neural-network-in-C++
 This repo contains the source code for a 3 layered neural network classifing handwritten digits of MNIST dataset.
 
  ## Prerequisites 
      - Code Blocks
  
  ##Running the code
    Open .cbp file in Code Blocks, build and run it.
    *This project uses windows.h header file for printing the image of digits*
